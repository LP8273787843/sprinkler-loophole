# The Sprinkler Loophole — Team C

Interactive page for the Session 10 "Logic Detective" activity (Computational Thinking, Bond University).

The bug: `currentHour ≥ 5 OR currentHour < 8` is true for every hour, so the sprinkler runs all day and all night. The fix swaps `OR` for `AND` inside each window and keeps the `OR` that joins morning and evening.

Open `index.html` in a browser to play with the garden, follow the hand trace, see the fix, copy the AI prompts, run the test table, tick the verification checklist and use the 2-minute presentation script.
